Assertion (A): Every point of the feasible region of a Linear Programming Problem is an optimal solution. Reason (R): The optimal solution for a Linear Programming Problem exists only at one or more corner point(s) of the feasible region.

Formula / idea Feasible solution: satisfies all constraints. Optimal solution: a feasible point giving the best value of ZZZ.

    A is false\text{A is false}A is false
  2. 2

    R: this is the corner point theorem of the textbook.

    R is true\text{R is true}R is true

  3. 3

    A is false, so R cannot explain A.

  4. 4
